castle+

A reverse proxy and process supervisor I wrote from scratch in C++ on epoll. It terminates TLS, launches and health-checks the services behind it, and streams request bodies of any size in bounded memory. It also handles per-IP rate limiting, live certificate reloads, and admin commands over a Unix socket.

You're reading this page through castle+.

Bowl Street Journal

Our team's winning HackNC 2026 project: a budgeting game for college students, built around the hackathon's Frutiger Aero theme. Its assistant, Gill Gates, is a goldfish built on Gemini who answers questions about your accounts and spending, out loud if you want. CPU Emulator

A CPU emulator in Rust with its own instruction set, EM (Emulator Machine code), and an assembler to go with it. Programs run step by step on a BIOS built with that assembler, shown live in a Raylib window. A companion Python app lets you write your own EM programs.

SwiftSearch

My first big project I ever did, mainly to help me learn multithread design after I took Operating Systems. It uses available threads to perform a search operation to find words or phrases in a series of files. To test this I created a Python Script to autogenerate files for testing.
